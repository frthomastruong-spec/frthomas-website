✝ Quản trị website

Sửa chữ trên trang chủ frthomas.com trực tiếp tại đây.

Bước 1 — Kết nối GitHub

Chỉ cần làm một lần duy nhất trên máy này.

1. Mở github.com → ảnh đại diện → Settings
2. Kéo xuống Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
3. Repository access → chọn Only select repositories → chọn frthomas-website
4. Mục Permissions → Contents → chọn Read and write → Generate token
5. Copy mã token vừa tạo, dán vào ô dưới:

Mã này chỉ lưu trong trình duyệt của anh, không gửi đi đâu khác.
